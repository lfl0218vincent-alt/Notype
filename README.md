# Notype for Mac

让想法，自然落字。在原输入框里说话，将整理或翻译好的文字填回光标位置，由你检查后手动发送。

当前发布：**0.9.13（build 64）**。这是公开安装包与教程仓库，不包含应用开发源码。

## 0.9.13 更新

- 长按 Control 约半秒，直接生成当前聊天的回复，跳过“总结 → 帮我回复”。Discord 支持无需选中文字，定位当前已加载的最近对方消息。
- 微信桌面版新增本地文字识别：仅在长按 Control 时读取当前聊天窗口画面，图片只在内存处理，不保存、不上传；只将识别出的聊天文字交给你配置的文字 API。需要 macOS 14+ 及屏幕录制权限，仅能读取当前可见内容。
- 快捷回复支持三条候选、中文表达想法、语音编辑和逐渐显示动画；紧凑黑色卡片采用 14 号居中文字，长内容滚动。点击复制图标后关闭卡片，由你检查并粘贴发送。
- “未自动填入”卡片收紧留白、缩小正文；状态在左上角、复制在右下角。中文输入和翻译输入都显示最终文字，原语音药丸尺寸不变。
- 首页、设置、历史和词典布局精简，搜索框增高，复制及划词操作增加悬停反馈。
- 改用固定本地签名证书；首次从旧签名升级可能需要重新关联辅助功能或钥匙串访问，后续是否保留授权以 macOS 实际结果为准。现有设置、历史、词典和 API Key 保留。

已有 0.8.0 或以上版本：在 **设置 → 关于与更新 → 检查更新** 后选择 **一键更新至 0.9.13**。应用仅在点击后检查和安装，不会静默更新。

## 安装前先看

- 适用 Apple Silicon（M 系列）Mac；系统部署目标为 macOS 13 或以上。当前构建在 macOS 27.2 验证，其他版本仍需实际验收。没有 Intel、Windows 或手机安装版。
- 当前采用固定本地自签名证书，尚未经过 Apple Developer ID 签名和公证。首次打开可能被系统阻止，请先阅读安装教程；GitHub 发布不代表 Apple 已审核。
- 需要麦克风及辅助功能权限，并使用你自己的 API Key。安装包没有附带他人的密钥、历史或账户额度。
- 无需安装 Xcode、Python、Node.js 或模型文件。API 是在线服务，识别和文字处理需要联网；服务费用及可用性以你的账户为准。

## 三步开始

1. 下载上面的 **Notype-Mac-AppleSilicon.zip**，解压，把 **Notype.app** 放入“应用程序”。请勿下载 GitHub 自动生成的 `Source code (zip)` 作为安装包。
2. 按 [安装教程](INSTALL.md) 开启权限，再按 [API 配置教程](API-SETUP.md) 选择服务商并保存你自己的 Key。
3. 在空白输入框里单按并松开 **Fn**，说话后再按 **Fn**。文字会自动尝试填入，不自动发送。**Fn + Shift** 开始翻译，结束仍按 Fn。

想让 Codex 帮助安装：把 [给 Codex 的安装指令](CODEX-INSTALL.txt) 全文复制到自己电脑上的 Codex，并允许它访问需要的文件和应用。系统身份验证、账户登录、付款和密钥填写由你本人完成。

## 功能

- 原语言语音输入、整理与翻译，完成后填回原输入框，不自动发送。
- 划词翻译、结合聊天上下文的总结、回复草稿、复制和系统朗读；可在首页关闭。
- 长按 Control 的快捷回复与表达想法；Discord 自动读取已加载消息，微信通过本地 OCR 读取可见聊天。
- 本地历史与个人词典，支持设置文本保留时间。
- 开始/结束提示音试听、快捷键检测、状态栏图标开关。
- 设置及 Notype 菜单中的“检查更新”，支持验证后下载、安装和重新打开，保留原数据。
- 累计用量统计与每页 26 周的使用日历，可用左右箭头翻看早期记录。

## 数据与反馈

录音会发送到你选择的语音服务；识别文字和词典用于文字整理/翻译。使用划词总结或生成回复时，所选文字及同一会话已加载的附近文本会发送至文字服务，生成回复还会发送你填写的想法。微信快捷回复需用户授权屏幕录制，只在长按 Control 时取得当前窗口画面并本地识别，图片不保存、不上传；识别出的消息文字会发送至文字服务。API Key 保存在当前 Mac 的钥匙串，历史与词典保存在当前用户的本地数据目录。删除历史文本后，日期、字词数和时长等统计可能继续保留。

账户和模型权限因人而异，不能仅凭“Key 已保存”判断服务已连通。首次使用请按教程完成一条无私密内容的实测。模型生成的名称、数字和语气请在发送前检查。

遇到问题可在 [Issues](https://github.com/lfl0218vincent-alt/Notype/issues) 提交 macOS 版本、Notype 版本和错误提示。请勿上传 API Key、私人聊天记录或录音。
